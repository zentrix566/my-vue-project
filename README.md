# 个人主页 · zentrix566.github.io

几个用 Vue 3 写的个人小玩具，统一收拢在这个站点里，点开即玩。本仓库即 GitHub 个人主页仓库 `zentrix566.github.io`，推送到 `main` 后由 GitHub Actions 自动构建并发布到 Pages，访问地址 https://zentrix566.github.io 。从原 `my-index` 个人索引站迁移而来。

## 主要功能

- **世界杯 · 点球大战（`/worldcup`）**：俯视点球点近景，拖拽调整角度和力度射门，10 次挑战 AI 守门员。
- **江阴保卫战 · 形势图（`/jiangyin`）**：清军与义军交战路线互动地图，点箭头看具体事件与经过。
- **400 米间歇训练（`/interval-training`）**：配速趋势图、评级、日历与导入导出。
- **多米诺骨牌（`/domino`）**：鼠标画一条路线生成骨牌，点推倒，连锁波沿曲线一节节倒下。
- **毛笔书法（`/calligraphy`）**：宣纸上书写，停笔 2 秒自动优化成大师笔法，可向标准字形靠拢。
- **中国官职 · 古今对比（`/officials`）**：以现代行政级别为轴，横向对比各王朝相当官职，支持王朝、级别筛选。
- **炉石魔网 · 脸伤计算器（`/nexus`）**：输入法强与场上怪血量，模拟随机砸怪溢出，算脸伤期望、最大最小与分布。
- **擂台投注 · 火柴人格斗（`/fight`）**：红蓝火柴人逐招对打（直拳、重拳、上勾拳、扫堂腿、飞踢，怒气满放波动拳），带暴击、闪避、击倒与伤害飘字；下注猜胜者赢双倍，快速投注模式可自动连打，统计多少轮把本金输光。
- **中国历史 · 风流人物长卷（`/history`）**：从炎黄传说到当代的横轴时间轴，覆盖 23 个时期、约 400 位人物与完整帝王序列。**按帝王/统治者分栏**，👑 统治者居中突出、风流人物并排展示；卡片显示生卒与**享年**，帝王/人物名以「庙号/年号-本名」呈现（如 唐太宗-李世民、崇祯帝-朱由检），并按即位年排序。各朝代已补全主要君主并打上**序位标签**（西汉1…、明朝1–16、清朝1–12、唐1–21+武周、东汉1–14、十六国/南北朝/五代十国按政权分组列出继承关系）；从史料文档提取的**著名历史事件**（楚汉之争、黄巾起义、淝水之战、安史之乱、靖难之役、鸦片战争等）一并并入时间轴、按年份穿插。页面**顶部新增可折叠「更新日志」**面板（数据见 `src/data/changelog.js`）。历史数据存放在 `src/features/history-timeline/data/chineseHistory.json`，改内容直接编辑该 JSON 即可。顶部与浮动条均为普通搜索栏，可搜人物、事件与典故；搜索时整条时间轴保留并高亮首条命中，事件卡片直接标明年份。
- **历代地图 · 疆域城邑（`/dynasty-map`）**：以今日中国省级区划为底图（阿里云 DataV GeoJSON，运行时拉取不打进包体），下拉切换**西汉末年、东汉末年、三国、盛唐、北宋、南宋、元、明、清**九个时期，在图上标注历代都城、州郡重镇、一般城邑与边关要塞的今址（如长安≈西安、宛城≈南阳、建康≈南京），三国时期按魏蜀吴阵营着色。地图呈接近俯视的**平面图**（初始视角已拉近），**点击省份使其立体凸起**并染上该朝主题色，右侧栏自动列出该省境内本朝可考的城邑；城邑标记按类型区分颜色，悬停/点击查看古名、今址与说明。工具栏提供复位视角、自动旋转、显示全部城名开关。基于 echarts + echarts-gl。
- **更新日志 · Changelog（`/changelog`）**：独立页面按提交日期展示项目主要功能与数据更新，每天一条（数据见 `src/data/changelog.js`）；首页「更新日志」卡片与历史页均可进入。
- **国外历史时间轴（`/world-history`）**：在「中国历史 · 时间轴」基础上，支持查看国外国家与文明的统治者、人物与事件，同样按时间轴呈现，可在页面顶部切换。
- **沧海一声笑 · 古琴和曲（`/canghai`）**：月下沧海、孤剑侠客的意境场景，五弦下落音符和一曲《沧海一声笑》，D/F/G/J/K 拨弦命中，按准确度评 S/A/B/C/D 境界。
- **大臣模拟器 · 宦海沉浮（`/minister`）**：卡牌抉择式官场模拟（Reigns 风格）。扮演大雍朝官员处理早朝、六部、贿赂、党争、弹劾等事件，平衡圣眷、政绩、名望、家财四维——任一维归零或涨满都仕途终结；每三年京察升降官阶，撑满二十年可告老还乡并获谥号。内置 39 个事件及随机风险支线，含寒门、世家、军功三种出身。
- **喜峰口 · 大刀夜袭（`/xifengkou`）**：1933 年 3 月 11 日夜喜峰口战役白台子夜袭模拟，扮演二十九军大刀队员摸进日军营地——哨兵提灯巡逻带视野锥、巡逻队游走、警报后帐篷里日军惊醒；灯光外潜行、背后挥刀暗杀，120 秒夜袭窗口内歼敌后从撤离点撤出，按歼敌数评级。配乐为 Web Audio 实时合成的《大刀进行曲》主旋律片段与进行曲鼓点（无音频文件），另有挥刀、枪声、号角等合成音效。
- **宠物模拟器（`/pet`）**：云养毛孩子，可选哈基米橘猫、修勾大狗、兔团子、仓小橘仓鼠四只宠物，各自独立的等级、金币与存档槽位。喂食（零食/正餐/最爱三档）、抚摸、洗澡、睡觉四类互动，饱腹/心情/精力/清洁四项状态随时间自然衰减，状态过差会生病发抖需看医恢复；逗宠小游戏限时点中飞动的网球赚金币换心情；离线超过 5 分钟回来时按离开时长结算衰减（最多 4 小时）。进度自动存入浏览器 localStorage，可随时重置单只宠物。
- **火柴人格斗 · 龙潭虎穴（`/stickfight`）**：火柴人只身连闯六层贼窝，清空敌人后出口开启、逐层突入。A/D 移动、W 跳平台、J 三段拳连击、K 踢腿击退、空中飞踢、Shift 翻滚闪避（带无敌帧可躲子弹与爆炸）、L 投掷炸药包（可连锁引爆、炸开木箱）。红色血液粒子落地形成持久血迹，血腥程度可关/正常/夸张；打手、持棍打手、枪手（瞄准线预警）与终层头目「铁拳王」（冲锋、投雷、半血狂暴）各怀绝技，木箱中可捡到炸药与医药包。
- **皇帝模拟器 · 日理万机（`/emperor`）**：奏折抉择式皇帝日常模拟（Reigns 风格）。拟年号登基后每月朱批一份奏折——赈灾、边患、党争、选秀、祥瑞灾异共 52 个事件（低属性时额外触发国库告急、军心浮动等危机事件），平衡国库、民心、军力、朝纲、圣躬五维，任一归零即亡国；批完腊月岁末结算税银军饷，健康归零或寿数已至则驾崩，史官按政绩上庙号谥号（哀宗至仁宗，在位满五十年隐藏结局「圣祖」），右侧史官记事实时记录每一笔朱批。开局可勾选**快速模式**：自动批量批阅一路直达结局，在岗界面可「接管」转回手动或「直接看结局」瞬间模拟到结尾；普通模式朱批结果与岁末结算卡显示 5 秒倒计时后自动进下一道，倒计时内点按钮可立即跳过。
- **模拟驾驶 · 练车找手感（`/driving`）**：俯视 2D 小车 + 简化自行车模型物理，给练车的新手和久没摸车的人练方向手感。四个模式：**变道练习**（三车道连续变道，考打灯时机与平顺度）、**转弯练习**（网格路口连续左右转，考导向车道与弯中车速）、**掉头练习**（缺口掉头，统计揉了几把方向）、**综合路考**（变道+左右转+掉头串成路线，到终点出 S/A/B/C/D 成绩单与教练式点评）。科目三式评分：压路缘、压实线、逆行、未提前打转向灯、忘关转向灯、弯道超速均扣分；转向灯转完弯随方向盘回正自动回位，屏幕下方有实时方向盘转角指示器辅助练"打多少、回多少"。键盘 W/S/A/D 或方向键驾驶、Q/E 转向灯、R 重开、Esc 暂停，手机可用屏幕虚拟按键；支持音效开关与各模式最佳成绩记录（localStorage）。
- **北京地铁 · 站站距离（`/subway`）**：覆盖北京全部运营线路（数据取自高德地图线网 JSON，27 条线、411 座去重车站，打包进前端纯本地运行）。两种用法：① **站站规划**——输入起终点（下拉标明"地铁站点"），Dijkstra 跨线求最短距离路径，给出总公里、**换乘次数**、**乘车区段**，并逐段展开**每一站之间的距离**明细；若系统选的路线不是你实际走的，可勾选"手动指定线路顺序"（如 `1,2,3,4`）强制按你换乘的线路走，互换起终点时线路顺序会自动反转。② **线路浏览**——选一条线，列出相邻站间距与累计距离（环线回到起点）。站间距离用 haversine 直线距离近似，无需联网。线路与规划结果均套用**北京地铁官方主题色**（线路徽标、途经线路 chip、浏览表头、选线下拉边框按官方线色显示，色表见 `precompute_subway.py` 的 `LINE_COLORS`）；规划结果以带边框的方框呈现总距离、换乘次数与乘车区段。
  - **人生倒计时（`/countdown`）**：输入生日与性别，估算距 35 岁斩杀线、退休与预期寿命还剩多久；样式自包含，纯前端本地计算，无需联网。
- **体重变化 · 趋势分析（`/weight`）**：按月记录体重，看整体走势、分年度变化和每月增减多少斤，**悬停任意节点**可见最重/最轻/最新等关键信息。
- **端到端加密 · 云端密文存储（`/secure-storage`）**：本地用 ECIES（ECDH P-256 + AES-256-GCM）加密后再上云，云端只存密文；私钥本机保存仅用于解密，没有密钥连管理员也解不开你存了什么。可生成密钥对、加密生成密文、模拟云端只存密文、输入私钥还原明文，并演示"无密钥解不开"。
- **当代人物追踪（`/contemporary-figures`）**：按领域收录当代人物，查看出生日期、年龄与距下次生日的天数，以时间轴呈现主要事迹；可为每个人撰写观察笔记、标记追踪状态（观察中/关注中/已搁置），数据存于浏览器本地。人物种子数据集中在 `src/features/contemporary-figures/data/figures.js`，改这一个文件即可增删人物。
- **人物生平 · 纪年查询（`/biography`）**：输入历史人物姓名（如 苏武、王莽、苏轼），调用火山引擎方舟大模型整理输出可直接复制的纯文本年谱：首行「姓名（生卒年），朝代身份」，其后按时间由早到晚写主要事迹（时间、当时年纪、事件简述，相邻相关事件合并到同一行使排版饱满，**事迹最多 5 行**），末行写卒年与终年。纪年一律用数字年份（公元前写"前XXX年"），不使用年号；非正常死亡（毒杀、赐死、斩杀、车裂等）会交代致死之人与方式，自然病逝则简写。
- **现代职业 · 古代岗位（`/career-roles`）**：输入现代职业或行业，对照常见岗位（公务员、收银员、流水线工人等）的古代叫法，也可让火山引擎方舟大模型推想任意现代行业对应的古代职位，返回朝代、对应理由与主要职责。

## 环境变量配置

「人物生平 · 纪年查询」与「现代职业 · 古代岗位」需要调用大模型接口，支持两种提供方（**火山引擎方舟优先**，未配置方舟时自动回退 DeepSeek），密钥通过环境变量注入，**不写进代码、不提交版本库**。

在项目根目录复制 `.env.example` 为 `.env`，填入真实密钥：

```bash
cp .env.example .env
```

```ini
# .env（已被 .gitignore 忽略，不会提交）
HUOSHAN_KEY=你的火山引擎方舟 API Key（优先，模型 ark-code-latest）
DEEPSEEK_KEY=你的 DeepSeek API Key（回退）
```

密钥采用不带 `VITE_` 前缀的变量名，仅在 `vite.config.js` 的开发/预览代理中读取，由 Vite 服务器在转发请求时注入 `Authorization` 头——前端代码与构建产物里都不包含密钥，同时绕开浏览器跨域限制。当前使用的模型名与提供方通过虚拟模块 `virtual:llm-config` 在构建期注入前端（dev/build 行为一致）。配置后直接 `npm run dev`（或 `npm run preview`）即可使用，前端请求 `/ark-api/chat/completions` 会被代理到火山方舟 Coding 接口（`https://ark.cn-beijing.volces.com/api/coding/v3`）或 DeepSeek 官方接口（`https://api.deepseek.com`）。

> 注意：该代理仅在 Vite 开发/预览服务器下生效。若把 `dist/` 部署到纯静态主机，需另行配置一个等价的服务端代理（或 Serverless 函数）转发到对应接口并带上鉴权头。

## 运行方式

安装依赖：

```bash
npm install
```

启动开发服务器（默认 http://localhost:5173）：

```bash
npm run dev
```

构建生产产物（输出到 `dist/`）：

```bash
npm run build
```

本地预览构建产物：

```bash
npm run preview
```

## 部署（GitHub Pages）

本仓库已配置 GitHub Actions 工作流（`.github/workflows/deploy.yml`）：推送到 `main` 分支即自动 `npm run build` 并把 `dist/` 发布到 GitHub Pages，无需手动上传产物。

首次启用需在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**（只设一次）。

> 注意：「人物生平 · 纪年查询」与「现代职业 · 古代岗位」依赖 Vite 开发服务器的密钥代理，在线版（GitHub Pages）不可用，仅本地 `npm run dev` 可用，其余功能均为纯前端、线上正常。
